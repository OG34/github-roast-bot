# GitHub Roast Bot 🔥

A web app that fetches a GitHub user's public profile and repositories, then uses Claude (Anthropic AI) to generate a funny, sarcastic roast.

## Features

- Enter any GitHub username and get a personalized roast
- Pulls public profile data and up to 100 repos via the GitHub API (no auth needed)
- Roast is generated by Claude based on repos, languages, stars, bio, and more
- Copy the roast to clipboard with one click
- Dark, GitHub-inspired UI

## Stack

- **Frontend:** Vanilla HTML/CSS/JS (single page, no framework)
- **Backend:** Node.js (`http` module, no Express)
- **AI:** Anthropic Claude via `@anthropic-ai/sdk`
- **Data:** GitHub REST API (public endpoints)

## Setup

```bash
npm install
cp .env.example .env
# Add your Anthropic API key to .env
npm start
# Open http://localhost:3000
```

## Environment Variables

| Variable | Description |
|---|---|
| `ANTHROPIC_API_KEY` | Your Anthropic API key (required) |
| `PORT` | Port to run the server on (default: `3000`) |

## Development

```bash
npm run dev   # starts with --watch for auto-restart on file changes
```
